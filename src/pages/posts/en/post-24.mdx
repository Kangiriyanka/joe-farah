## Intro 


&nbsp;

Inspired by the GNOME app <a class="secondary-a "href= "https://gitlab.gnome.org/World/exercise-timer">Exercise Timer</a>, I decided to 
make custom timers in React given that my previous posts have been focusing on applications that leverage it. In this post, we'll define tasks or activites as <u>Missions</u>, because 
it sounds nice and implies a sense of duty. A Mission constitutes of timed sessions (workTime) with an associated rest (restTime) for a number of sets. I also threw in a preparation time, a countdown before the mission starts.

&nbsp;

 Our first priority will be making cards that display the general overview of the mission, providing the total time it takes, the set breakdown, etc. Our second priority will be
linking the custom timer that respects those times.


&nbsp;

## Making a Mission Card

### Vanilla Layout

&nbsp;

Our starting point is defining <span class="bold-rounded">Mission</span> object with the properties below: 

- an id
- a title
- the work time (in seconds)
- the rest time (in seconds)

- the number of sets

It's worth nothing that the times are stored internally in seconds for consistency, and formatted properly to strings for readability. This will be covered shortly.

### Formatting Times 

&nbsp;


Right now, the times shown on the cards are in seconds, but we can convert them for readability (and decency). We'll make a helper function <span class="bold-rounded">formatTimer</span> that will cover 3 cases where the time is:

&nbsp;


1. is greater than or equal to an hour, e.g., 4500 seconds →  1 hour and 15 minutes
2. is less than an hour but greater than a minute, e.g., 1300 seconds →  21 minutes and 40 seconds
3. is less than a minute, e.g., 58 seconds → 58 seconds






&nbsp;

<i>Time formatter where the remainders carry all the workload!</i>
```typescript

function formatMissionTime(seconds: number, decimals = 2) {
  const remainderSeconds = seconds % 60;
  const minutes = seconds / 60;
  const remainderMinutes = minutes % 60;
  const hours = seconds / 3600;

  // Greater or equal to an hour
  if (hours >= 1) {
    return `${Math.round(hours)} hour${
      Math.floor(hours) > 1 ? "s" : ""
    } and ${Math.floor(remainderMinutes)} minutes`;
  }
  
  // Less than an hour but greater than a minute
  if (minutes >= 1) {
    return `${Math.floor(minutes)} minute${
      Math.floor(minutes) > 1 ? "s" : ""
    }${remainder > 0 ? ` and ${remainder} seconds` : ""}`;
  }

  // Seconds remain
  return `${remainderSeconds} second${remainderSeconds !== 1 ? "s" : ""}`;
}
```
